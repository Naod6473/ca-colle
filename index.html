Ctrl + C
  1. Ouvre l'annonce en entier. Sur Indeed, clique sur le titre de l'offre pour l'avoir seule sur la page. Sur LinkedIn, clique d'abord sur « Voir plus » sous la description.
  2. Sélectionne le texte du titre jusqu'au profil recherché (sur France Travail, jusqu'à « Profil souhaité » inclus).
  3. Copie (Ctrl + C, ou Cmd + C sur Mac) puis colle ici (Ctrl + V).
  4. Sur téléphone : appui long sur le texte, « Tout sélectionner », « Copier ». Ou fais une capture d'écran et joins-la.

Pas grave si tu copies trop : l'app retire toute seule les boutons, menus et mentions du site.
